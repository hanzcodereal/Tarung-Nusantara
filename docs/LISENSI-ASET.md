# Lisensi aset

## Dibuat khusus untuk game ini

Gambar arena, logo, ikon aplikasi, sprite penonton, musik, dan efek suara dibuat dengan skrip di `tools/assets/` (Python, Pillow, NumPy, SciPy, ffmpeg). Lagu-lagu adalah gubahan asli bergaya instrumen daerah, bukan salinan lagu daerah yang sudah ada. Petarung digambar langsung oleh kode game (`game/Renderer.kt`).

## Huruf pihak ketiga

| Huruf | Pemegang hak cipta | Lisensi |

| Lora (Bold, instans statis dari huruf variabel) | Cyreal | SIL Open Font License 1.1 |

Teks lisensi lengkap: https://openfontlicense.org. Kedua huruf dipakai tanpa perubahan desain. Lora Bold dibuat dengan menetapkan sumbu bobot 700 pada huruf variabel aslinya.

## Catatan simbol

Sayap di arena Stadion Garuda adalah bentuk geometris karangan sendiri, bukan lambang negara. Bendera merah putih kecil di tribun hanya sebagai hiasan penonton.
